# 🍕 Italian PIZZA

A modern and responsive pizza restaurant website featuring delicious pizza collections, restaurant information, and an engaging food ordering experience.

## 👩‍💻 About the Project
Italian PIZZA is a frontend web development project designed to showcase a pizza restaurant through an attractive interface, delicious food visuals, and a user-friendly ordering experience. It includes menu browsing, cart functionality, and responsive layouts for a smooth user experience.

## ✨ Features
-  Home page with an attractive hero section
-  About page showcasing the restaurant
-  Popular pizza categories and menu
-  Add-to-cart functionality
-  Food ordering concept
-  Contact page with contact information
-  Responsive design for all devices
-  Modern UI with attractive visuals

## 🛠️ Tech Stack
-  HTML5
-  CSS3
-  JavaScript
-  Bootstrap 5
